# Series: AI + YouTube = RpXX Juta/Bulan?

Locked YouTube thumbnail recipe for the channel-breakdown / evidence series.

| File | Role |
|------|------|
| `thumbnail.md` | Hard rules + YAML recipe (layout, colors, copy stack, export size) |

Episodes set in `project.yaml`:

```yaml
style: evidence
series: ai-youtube-idr
```

- `style: evidence` — talking-head + real evidence stills (video grammar).
- `series: ai-youtube-idr` — thumbnail/brand lock only (agents must not redesign).

House talking-head tutorials stay on `style: tutorial` (optionally with `series: odoo-studio-agentic-ai`).
