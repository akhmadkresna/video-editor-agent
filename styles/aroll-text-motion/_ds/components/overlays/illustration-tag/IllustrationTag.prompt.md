IllustrationTag — a bare white icon stacked over a word, popping in from a screen corner near the speaker (the "words surrounding the speaker" pattern) — no pill/background, just icon + label.

```jsx
<IllustrationTag icon="zap" label="Fast" corner="top-right" />
```

Icon set is Lucide via CDN — flagged substitution, no icon assets were supplied in source material.
